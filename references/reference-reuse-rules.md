# 参考方案复用和污染控制

## 目录

1. 参考材料分类
2. 章节级复用判定
3. 四类处理结论
4. 禁止继承内容
5. 改写步骤
6. 残留词表

## 1. 参考材料分类

- 外地同类可研：主要参考章节结构、论证顺序、表格形式和通用写法。
- 公司标准方案：主要参考功能组织、技术能力和产品术语。
- 厂商专项方案：主要参考特定系统的技术路线、接口和迁移线索。
- 历史报名或响应材料：主要作为现状问题、能力和历史价格线索。
- Word参考模板：只参考样式和版式，正文和元数据均视为污染源。

## 2. 章节级复用判定

不要对整份文件给出单一相似度。逐章记录：

- 结构相似度：高、中、低；
- 业务范围相似度：高、中、低；
- 事实可信度：正式、材料线索、仅作参考；
- 目标章节；
- 允许内容；
- 禁止内容；
- 改写强度；
- 残留扫描词。

## 3. 四类处理结论

| 类型 | 处理 |
|---|---|
| 结构复用 | 保留标题组织、论证顺序或表格结构，全部替换项目事实 |
| 改造 | 保留部分通用论证，按目标项目范围和政策重写 |
| 删除 | 业务对象、建设范围或结论不适用，不能进入目标稿 |
| 用户粘贴 | 目标项目另有专项方案，Skill只预留目录和接口说明 |

“可以直接复用”通常只指结构或纯通用定义，不等于整段原文复制。

## 4. 禁止继承内容

默认禁止继承：

- 地域、行政区划和单位名称；
- 医院等级、床位、人员、业务量和现有系统；
- 建设主体、业务对象和覆盖范围；
- 项目名称、负责人、联系人和供应商；
- 投资、报价、比例、工期和年度安排；
- 绩效目标、基线、目标值和验收结论；
- 项目专属政策文号和地方政策；
- 参考项目的风险判断和可行性结论；
- 页眉、页脚、批注、图片、超链接和文档元数据。

## 5. 改写步骤

1. 提取目标段落的论证功能，而不是先复制文字。
2. 列出目标项目可用的事实ID和范围ID。
3. 删除所有参考项目变量。
4. 使用目标项目事实重建主语、对象、范围和因果关系。
5. 无目标事实支持的句子删除或标记 `【待补充】`。
6. 将宣传性和绝对化表述改为可论证的审慎表述。
7. 把参考项目专有词加入残留词表并执行扫描。

## 6. 残留词表

至少收集：

- 项目全称和简称；
- 地名、单位名和院区名；
- 供应商及产品专名；
- 联系人、电话号码和邮箱；
- 特有金额、比例、年份和工期；
- 特有指标和等级目标；
- 旧页眉页脚文字；
- 用户指定禁止出现的术语。

词表每行一个词；正则表达式仅在确有必要时使用。扫描结果为零不等于事实正确，仍需执行事实和范围校验。
