# Skill 问题池

## 使用规则

- 编号格式：`DEV-001`起；编号建立后不重编。
- 严重程度：`P0=阻断`、`P1=高`、`P2=中`、`P3=低`。
- 分类：`A`为不改变业务边界的工程修复；`B`为需要业务确认的事实、范围、投资、政策或验收决策。
- 状态只用：`新建`、`定位中`、`待用户决策`、`待实施`、`处理中`、`待验证`、`已验证`、`不处理`。
- 发现问题先登记；当前任务明确选择后才进入单根因修改轮次。
