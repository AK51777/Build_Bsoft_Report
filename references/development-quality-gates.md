# Skill 硬质量门禁

## 严重程度

| 级别 | 含义 | 默认动作 |
|---|---|---|
| P0 / 阻断 | 会导致项目、范围、投资、结论或交付实质错误 | 阻断相关链路 |
| P1 / 高 | 重要事实无依据、口径冲突或合规风险 | 发布前解决或明确保留 |
| P2 / 中 | 影响理解、一致性或可执行性 | 登记并排期 |
| P3 / 低 | 语言、格式或非关键优化 | 进入问题池 |

## 核心指标

| 维度 | 指标 | 通过阈值 | 失败级别 |
|---|---|---|---|
| 一致性 | 项目名称、建设周期、总投资与唯一已确认主事实的冲突数 | 0 | P0 |
| 一致性 | 同一`SCOPE-ID`建设方式不一致数 | 0 | P0 |
| 数字 | 项目专有确定性数字的事实ID或计算链覆盖率 | 100% | P0 |
| 数字 | AI自行生成且无来源的项目数字 | 0 | P0 |
| 范围 | 已确认范围项正文承载率 | 100% | P0 |
| 范围 | 正文建设项反查范围ID覆盖率 | 100% | P0 |
| 范围 | 凭空新增系统、删除项回流、建设方式混淆 | 各为0 | P0 |
| 建设装配 | 客户清单显示快照和来源顺序覆盖率 | 100% | P0 |
| 建设装配 | 已确认模块所选块等于唯一标准标题完整子树 | 100% | P0 |
| 建设装配 | 标准正文逐块文本哈希相等率 / 其他同名子树混入数 | 100% / 0 | P0 |
| 建设装配 | 相似、缺失、歧义模块未完成人工决定数 | 0 | P0 |
| 目标 | 有需求、范围项或确认目标支撑的建设目标比例 | 100% | P0 |
| 完整性 | 适用章节必须问题、必备表格和证据边界覆盖率 | 100% | P1；核心缺失为P0 |
| 知识 | 声称使用知识的内容可追溯到当前快照package/catalog和block/clause ID | 100% | P1；虚假声称为P0 |
| 污染 | 其他项目名称、单位、金额、指标和旧结论残留 | 0 | P0 |
| 交付 | 正式稿TBD、TODO、批注、内部提示、Markdown和工作层追踪标记 | 0 | P0 |
| 交付 | DOCX哈希绑定的实际渲染检查页数/总页数 | 100% | P0 |

“一致”不等于“真实”。多个位置复制同一未确认值，仍按未确认处理，不能通过事实门禁。

## 门禁证据

- 每次运行保存run_id、输入哈希、脚本版本、检查数量、失败明细和输出哈希。
- 未实际运行的检查标记`not_run`，不能声称通过。
- 自动指标通过不代表业务已确认；事实、范围、投资、政策和验收目标仍以确认记录为准。
- 黄金案例必须比较可观察行为和数据契约，不写只匹配固定措辞或标题的脆弱测试。
